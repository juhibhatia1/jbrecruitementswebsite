# Pre-Deployment SEO Checklist

## ✅ Configuration Files

- [ ] `.env.local` created with production URL
- [ ] `.env.local` contains Google Analytics Measurement ID
- [ ] Google Search Console verification code added to layout.tsx
- [ ] Actual domain name replaces `jbrecruitment.com` in all files

## ✅ Content Verification

- [ ] All page titles are unique and descriptive
- [ ] All meta descriptions under 160 characters
- [ ] All images have descriptive alt text
- [ ] Logo displays correctly on all pages
- [ ] H1 tags present on all pages (only one per page)
- [ ] Internal links working properly

## ✅ Technical SEO

- [ ] SSL certificate installed (HTTPS)
- [ ] Sitemap accessible at /sitemap.xml
- [ ] Robots.txt accessible at /robots.txt
- [ ] 404 page exists and styled
- [ ] Mobile responsive on all devices
- [ ] Page load time < 3 seconds
- [ ] No broken links
- [ ] Canonical URLs set correctly

## ✅ Structured Data

- [ ] Organization schema validated
- [ ] FAQ schema validated
- [ ] Breadcrumb schema validated
- [ ] All schemas pass Rich Results Test

## ✅ Open Graph & Social

- [ ] OG image generates correctly (1200x630)
- [ ] OG tags validated with Facebook Debugger
- [ ] Twitter Card validated
- [ ] LinkedIn preview looks good
- [ ] Social media handles updated in structured data

## ✅ Analytics & Tracking

- [ ] Google Analytics installed
- [ ] Google Search Console property created
- [ ] Analytics tracking verified
- [ ] Event tracking tested (forms, buttons)
- [ ] Goals/conversions configured in GA

## ✅ Search Engine Submission

- [ ] Sitemap submitted to Google Search Console
- [ ] Sitemap submitted to Bing Webmaster Tools
- [ ] URL inspection in Search Console shows no issues
- [ ] Requested indexing for main pages

## ✅ Performance

- [ ] Core Web Vitals pass
- [ ] LCP < 2.5s
- [ ] FID < 100ms
- [ ] CLS < 0.1
- [ ] Images optimized (WebP format where possible)
- [ ] Fonts optimized

## ✅ Accessibility

- [ ] Color contrast ratios pass WCAG AA
- [ ] Keyboard navigation works
- [ ] Screen reader tested
- [ ] ARIA labels present where needed
- [ ] Skip to content link available

## ✅ Local SEO (if applicable)

- [ ] Google Business Profile created
- [ ] NAP (Name, Address, Phone) consistent everywhere
- [ ] LocalBusiness schema added
- [ ] Location pages created
- [ ] Local citations built

## ✅ Content Marketing

- [ ] Company description optimized with keywords
- [ ] Services clearly described
- [ ] Contact information easily accessible
- [ ] Clear calls-to-action
- [ ] Trust signals present (testimonials, logos)

## ✅ Off-Page SEO

- [ ] Social media profiles created
- [ ] Business directories listed (LinkedIn, Indeed, Glassdoor)
- [ ] Industry directory submissions
- [ ] Initial backlinks secured
- [ ] Press release prepared (optional)

## ✅ Monitoring Setup

- [ ] Google Search Console alerts configured
- [ ] Google Analytics reporting set up
- [ ] Rank tracking tool configured
- [ ] Uptime monitoring enabled
- [ ] Error tracking configured

## ✅ Documentation

- [ ] Team trained on SEO best practices
- [ ] Content guidelines documented
- [ ] Analytics access granted to stakeholders
- [ ] SEO maintenance schedule created

## 🚀 Post-Launch (Within 24 Hours)

- [ ] Verify all pages indexed
- [ ] Check for crawl errors
- [ ] Monitor Analytics for traffic
- [ ] Test all forms working
- [ ] Check all redirects
- [ ] Verify email notifications working

## 📊 Week 1 Tasks

- [ ] Review Search Console coverage report
- [ ] Check for mobile usability issues
- [ ] Review Core Web Vitals report
- [ ] Analyze initial traffic patterns
- [ ] Fix any critical issues found

## 🎯 First Month Goals

- [ ] All target pages indexed
- [ ] Branded keywords ranking
- [ ] No critical technical SEO issues
- [ ] 50+ organic sessions
- [ ] 5+ quality backlinks
