# Recent Changes

Use this folder as a lightweight handoff layer between Copilot sessions.

## Files
- `latest.md` — current short summary of the most recent meaningful AI interview work.
- `open-issues.md` — active bug buckets, likely hotspots, and next investigation targets.
- `prompt-template.md` — reusable prompt shape for fast, focused Copilot sessions.
- `TEMPLATE.md` — copy structure for future updates.

## Update rule
Update `latest.md` whenever you make a meaningful AI mock interview fix, optimization, or behavior change.

Keep each note brief and practical:
- what changed
- why it changed
- files touched
- validation done
- open follow-ups
